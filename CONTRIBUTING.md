# Contributing

Thanks for helping improve this unofficial LazyCat Microserver resource list.

## Rules

1. Prefer official or high-quality community sources. Skip pure ads / lottery posts unless they contain lasting technical value.
2. Keep the awesome-list style: one link per line, short description (usually one sentence).
3. Update **both** [README.md](./README.md) and [README-EN.md](./README-EN.md) in the same PR.
4. Put links in the right section (official map, tutorials, AI Pod, Skill/MCP, apps, experiences, etc.).
5. Prefer working URLs. For App Store apps, use a real package id when known (`cloud.lazycat.app.*` / `community.lazycat.app.*`). If the package id is unknown, link a Playground guide or docs page instead of guessing.
6. Do not invent package ids or product specs. Match [lazycat.cloud](https://lazycat.cloud/) / developer docs when possible.

## PR checklist

- [ ] Link opens and is relevant
- [ ] Chinese and English README both updated
- [ ] Placed under an existing heading (or a clearly named new subheading)
- [ ] Description is concise and non-promotional

## Prefer Issues for quick submissions

If you only have a link suggestion or a broken URL report, open an Issue with the templates under **New issue** — no need to open a PR for small tips.

## Local preview

Edit the Markdown files and open a PR against `main`.
