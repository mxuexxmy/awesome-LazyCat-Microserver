# Contributing

Thanks for helping improve this unofficial LazyCat Microserver resource list.

## Rules

1. Prefer official or high-quality community sources. Skip pure ads / lottery posts unless they contain lasting technical value.
2. Keep the awesome-list style: `- [Name](url) - description`.
3. Update **both** [README.md](./README.md) (English, primary) and [README-ZH.md](./README-ZH.md) in the same PR when possible.
4. Put links in the right section. Do not repeat the same URL elsewhere in the English README.
5. Prefer working URLs. For App Store apps, use a real package id when known. If unknown, link a Playground guide or docs page instead of guessing.
6. Do not invent package ids or product specs. Match [lazycat.cloud](https://lazycat.cloud/) / developer docs when possible.

## Prefer Issues for quick submissions

If you only have a link suggestion or a broken URL report, open an Issue with the templates under **New issue**.

## Local checks

```bash
npx awesome-lint README.md
```

## Pull requests

Edit the Markdown files and open a PR against `main`.
